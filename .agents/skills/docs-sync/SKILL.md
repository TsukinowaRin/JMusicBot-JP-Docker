---
name: docs-sync
description: コード、挙動、コマンド、運用手順、制約が変わり、project docs を正確に保つ必要があるときに使う。必要最小限の docs だけを更新し、docs/INDEX.md も同期する。観測可能な挙動や運用が変わらない作業には使わない。
---

1. ユーザーから見える挙動、コマンド、運用ルールのどこが変わったかを特定する。
2. 関連する docs だけを更新する。
3. 曖昧な説明より、具体的なコマンド、パス、期待結果を優先する。
4. 不要になった doc は削除するか、見つけやすい場所で obsolete と明記する。
5. 最後に、どの docs をなぜ更新したかを短くまとめる。
