---
name: handoff-sync
description: 作業を中断する前、担当を切り替える前、または checkpoint を残す前に使う。docs を見れば別エージェントがそのまま再開できる状態へ整える。雑な中断には使わず、停止点を明確に残したいときに使う。
---

1. `docs/WORKLOG.md` に、目的、変更、コマンド結果、未完了、次の一手、ブロッカーを追記する。
2. 複雑作業なら、`docs/EXECPLAN_*.md` の進捗、停止点、発見事項、判断ログを更新する。
3. `docs/REQS.md` に要求や acceptance criteria のズレがあれば反映する。
4. 次のエージェントが最初に読むべき文書と、最初に実行すべきコマンドを明示する。
5. 未確認箇所、失敗した試行、保留中の判断を隠さず残す。
6. 完了条件は「chat 履歴なしで docs だけを読んだ別エージェントが再開できること」とする。
